# Khaju — Portfolio

Personal portfolio of **Ahamed Mohiuddin** (professionally known as **Khaju**) — Full-stack Developer, Designer & Systems Builder.

## Folder Structure

```
khaju-portfolio/
├── index.html              # Main entry point
├── css/
│   └── styles.css          # All styles (extracted from original)
├── js/
│   └── main.js             # Interactivity (tilt, counters, filters, modal)
├── assets/
│   └── images/             # Place your images here
│       ├── profile.jpg
│       ├── design-1.jpg … design-8.jpg
│       └── video-1.jpg … video-3.jpg
└── README.md
```

## Quick Start

1. Open `index.html` in a browser, **or**
2. Serve locally:

```bash
# Python
python -m http.server 8000

# Node (if you have npx)
npx serve .
```

Then visit `http://localhost:8000`.

## Adding Images

Replace the placeholder paths in `assets/images/`:

| File              | Used for                  |
|-------------------|---------------------------|
| `profile.jpg`     | About section portrait    |
| `design-1.jpg` …  | Design gallery items      |
| `video-1.jpg` …   | Video thumbnail cards     |

Recommended sizes:
- Profile: ~800×1000 px
- Design items: ~800–1200 px wide
- Video thumbs: 16:9, ~1280×720 px

## Tech Stack

- Plain HTML5 + CSS3 + Vanilla JS
- Google Fonts (DM Sans + Space Mono)
- Lucide icons (CDN)
- No build step required
